⚠️ PRODUCTION DATABASE VERSION: MySQL 5.7+
================================================================================
Your database runs on MySQL 5.7+ (cPanel standard)

CRITICAL CONSTRAINTS FOR SQL QUERIES:
  • NO window functions (ROW_NUMBER, RANK, COUNT() OVER)
  • NO JSON functions (JSON_EXTRACT, JSON_ARRAY)
  • NO generated columns
  • Use utf8mb4_general_ci collation ALWAYS
  • ALL queries MUST use prepared statements

When writing SQL, refer to COMPLETE_DATABASE_SCHEMA_CLEAN.sql for syntax patterns.
See CLAUDE.md "DATABASE VERSION REQUIREMENT" section for full rules.

TROUBLESHOOTING
================================================================================
Error: "Unknown column"
→ Make sure ALL tables were created. Check import output for errors at top.

Error: "Duplicate foreign key"
→ Normal on re-import. Can run multiple times safely.

Error: "Collation not valid"
→ Your MySQL is very old. Use COMPLETE_DATABASE_SCHEMA_SAFE.sql instead.
