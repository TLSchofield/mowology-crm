# Ittai Design System v1.2 — the rules a design round must obey
Source of truth: `docs/design/ittai-v1.2/` (`tokens.json`, `tenant.config.json`, `spec/SPEC-v1.2.md`, `cd-source/` component previews) and the brand-book artifact https://claude.ai/artifact/YDZaYnmRc8CAbqtz8oC5uk. This file is the short version; when it and the spec disagree, the spec wins.

## Look
- **Tokens only.** Every colour is a CSS variable from `tokens.css` (generated: `node scripts/ittai-design/build-tokens.mjs`). No hex / rgb / hsl literals anywhere else. Never hand-write a tenant colour.
- **Inter** at 400 / 500 / 600 only. Sentence case. No text under 12 px (a scaled diagram's labels become real text).
- **Rows before cards.** One hairline list is the default shape. Cards only when the thing is a distinct object.
- **One dominant action per decision.** A filled primary button only where the item is urgent; every other action is a quiet text or outline button. If twelve equal filled buttons appear, nothing is the next action — redesign.
- **Status is icon + word, never colour alone.** Two vocabularies, one icon set (SPEC §2): task/operation status and AI-employee state never share words or glyphs. Blocked = octagon, attention = triangle, complete = check, queued/sync = cloud family (sync uses the cloud family only).
- **Nothing floating over content.** Main action pinned in the thumb zone on phones.

## Use
- **Touch targets** 44 px desktop, 48 px under 1024 px wide, 56 px for the main action, always labelled.
- **Contrast AAA**: 7:1 normal text (including meta, status, tenant-as-text) in light, dark and field; 4.5:1 large text and UI parts. Filled-button labels use `--on-tenant`, never a blanket colour.
- **Modes**: field > chosen theme (`data-theme`) > OS preference > light. Field mode is for outdoor crews: higher contrast, larger density.
- **Every display size**: 375, 768, 1024, 1440 (plus Tim's real screen). No sideways scroll. Below 1100 px decisions come first and stack.
- **Honest state**: nothing says "done" until the server confirms; design the pending / failed / offline states too.
- **Synthetic data** in every render.

## Frozen
- The Ittai symbol (lockup B) is frozen — use `assets/symbol/*.svg` unchanged, monochrome, no state input. The wordmark text is always "Ittai". Do not redraw, recolour or "improve" either.
- v1.2 is the baseline. A new idea that needs a new token or component is proposed in the notes, not invented in the render.
