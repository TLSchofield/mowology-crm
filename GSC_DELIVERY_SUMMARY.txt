================================================================================
                          THE ROOT CAUSE
================================================================================

Problem:
  Code hardcodes 'sc-domain:' prefix for ALL properties
  BUT your property is a URL-prefix type: https://mowology.ca
  
Identifier Mismatch:
  Code queries: /sites/sc-domain%3Amowology.ca/searchAnalytics/query
  Google has:  /sites/https%3A%2F%2Fmowology.ca/searchAnalytics/query
  Result:      404 Not Found ❌

Why Tokens Stay Valid:
  OAuth tokens authenticate users globally (not specific to properties)
  Property identifiers are separate routing information
  Invalid identifier + valid token = 404 anyway

================================================================================
                            THE SOLUTION
================================================================================

Core Fix:
  Store GSC property identifiers EXACTLY as Google returns them
  Don't transform them
  Validate format matches property type

Database Changes:
  ✅ Add api_site_url column (stores exact identifier)
  ✅ Add property_type column (tracks domain vs url_prefix)
  ✅ Add display_domain column (clean domain for UI)
  ✅ Auto-migrate existing data
  ✅ Non-breaking (old code still works)

Code Changes:
  ✅ Add validateSiteUrlFormat() function
  ✅ Use api_site_url verbatim (no transformation)
  ✅ Better error tracking
  ✅ Improved error messages
