STEP 1: CHECK DATABASE STATUS
────────────────────────────────────────────────────────────

  cd /path/to/mowology-crm
  php check-database.php

This shows:
  ✓ Tables that exist
  ✗ Tables that are missing
  Current MySQL version and database name


STEP 2: CREATE MISSING TABLES
────────────────────────────────────────────────────────────

If missing tables found, run:

  php apply-migrations-cli.php

This will:
  • Connect to your local MySQL
  • Create all required tables
  • Show progress
  • Verify everything worked


STEP 3: TEST QUOTE FORM
────────────────────────────────────────────────────────────

Visit the form:
  https://www.mowology.ca/jobFlow/getQuote.php

Submit a test quote and verify:
  • Form submits successfully
  • Quote appears in CRM dashboard
  • No error messages

TROUBLESHOOTING
────────────────────────────────────────────────────────────

Problem: MySQL connection failed
  → Make sure MySQL is running (MAMP, Docker, etc.)
  → Check credentials in public/app_config/config.php

Problem: Tables already exist errors
  → This is normal - script skips existing tables

Problem: Quote still fails after migration
  1. Run: php check-database.php
  2. Look for ✗ marked tables
  3. Check browser console (F12) for errors
  4. Review SYNC_DATABASE_INSTRUCTIONS.md
