KEY DESIGN DECISIONS
================================================================================

1. SERVICE PACKAGES drive everything
   → One package selection fills 70-90% of job automatically
   → Eliminates need for manual duration, crew, pricing, checklist entry

2. SMART DEFAULTS everywhere
   → Auto-select property (if only 1)
   → Auto-suggest crew (based on location)
   → Auto-calculate optimal time window
   → Auto-apply correct billing template

3. GUARDRAILS instead of warnings
   → Can't select unavailable crew (option disabled)
   → Can't choose conflicting time (auto-adjusted)
   → Incompatible billing template auto-switched
   → Schedule conflicts impossible

4. PROOF OF WORK defined at creation
   → Crew knows what's required before leaving property
   → Invoice blocked if checklist/photos missing
   → 100% compliance possible

5. RECURRING JOBS as parent + instances
   → Edit "this" vs "this and following" without complexity
   → Auto-generate individual job instances
   → Flexible scheduling patterns
