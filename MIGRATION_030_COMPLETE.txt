================================================================================
ERROR HANDLING
================================================================================

If migration fails, check:

1. MySQL version:
   SELECT VERSION();
   Should show: 5.7.x or higher

2. Database permissions:
   User must have: CREATE, ALTER, INDEX, FOREIGN KEY permissions

3. Foreign key constraint errors:
   If error: "Cannot add or update a child row..."
   Solution: Run migration 001 first (creates parent tables)

4. Duplicate table errors:
   If error: "Table already exists"
   Solution: Safe to ignore (IF NOT EXISTS prevents errors)

5. Collation mismatch errors:
   If error: "Collation mismatch..."
   Solution: Ensure database uses utf8mb4_general_ci
