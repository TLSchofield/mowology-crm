  THE PROBLEM (Root Cause)
================================================================================

Current State:
  ✓ GSC data synced successfully!
  Pulled 0 properties, 1 failed
  
  Failed properties:
  • https://mowology.ca: Failed to fetch GSC data for property https://mowology.ca

Root Cause Analysis:
  
  1. Property Registration in Google Search Console:
     • Type: URL-prefix property
     • Identifier: https://mowology.ca
     
  2. Property Storage in Database (gsc_properties):
     • Stored as: site_url = 'https://mowology.ca'
     • No metadata about property type
     
  3. Bug in /crm/gsc/sync-cron.php (line 223):
     $apiSiteUrl = 'sc-domain:' . preg_replace('|^(https?://)?sc-domain:|', '', $siteUrl);
     
     This line:
     • Takes: "https://mowology.ca"
     • Strips it: "mowology.ca"
     • Adds sc-domain: prefix: "sc-domain:mowology.ca"
     
  4. API Query:
     • Queries: /sites/sc-domain%3Amowology.ca/searchAnalytics/query
     • Google has: /sites/https%3A%2F%2Fmowology.ca/searchAnalytics/query
     • Result: 404 Not Found ❌
     
  5. Why Tokens Stay Valid:
     • OAuth tokens authenticate user, not properties
     • Tokens work globally for user's entire GSC account
     • Property identifiers are separate routing info
     • Invalid identifier → 404 (Not Found)
     • Valid token with invalid identifier → 404 anyway

Critical Insight:
  Google Search Console has TWO incompatible property type formats:
  
  • Domain Properties:       sc-domain:example.com (covers all protocols)
  • URL-prefix Properties:   https://example.com (covers exact domain+protocol)
  
  These are NOT interchangeable.
  Code assumes all are sc-domain: format, but property is url_prefix format.

  THE SOLUTION
================================================================================

Fix Overview:
  1. Add property type awareness to database schema
  2. Store API identifiers EXACTLY as returned by Google (verbatim)
  3. Validate identifier format matches property type
  4. Use verbatim identifiers in all API queries (no transformation)

    function validateSiteUrlFormat($siteUrl, $propertyType) {
        // NEW: Validates format matches type
        if ($propertyType === 'domain') return starts_with($siteUrl, 'sc-domain:');
        return starts_with($siteUrl, 'https://') || starts_with($siteUrl, 'http://');
    }
    
    function fetchGSCData($accessToken, $siteUrl, $propertyType) {

        // CORRECT: No transformation - use exactly as Google provided it

        curl_query(."sites/{$encodedSiteUrl}/searchAnalytics/query");
    }
