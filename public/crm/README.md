# Mowology CRM & Website

Professional landscaping services in Vancouver, BC.

## Structure
- `/img/` - All website images (hero, services, portfolio, team)
- `/css/` - Stylesheets
- `/js/` - JavaScript
- `/crm/` - CRM backend (password protected)
- `/docs/` - Documentation

## Image Naming
Format: `{purpose}-{description}-{size}.{ext}`

Example: `hero-lawn-care-1920x1080.jpg`

## Deploy
Push to GitHub → Auto-deploys to mowology.ca
