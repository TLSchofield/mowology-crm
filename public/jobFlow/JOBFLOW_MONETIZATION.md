# jobFlow Monetization

## Phase 2 — Conversion Optimisation

### Objective

Increase average job value and quote-to-booking conversion rate by:
1. Building trust before the user fills out the form
2. Gathering richer property data (micro-commitments)
3. Presenting contextual upsells at the review step
4. Creating urgency without being dishonest
5. Activating the referral channel post-submission

---

## Step 1 — Quote Form Enhancements

### Trust Badges

Three badges below the header tagline:
- "✓ Free estimate"
- "✓ No obligation"
- "✓ [dynamic response time message]"

The response time message is generated by `getResponseTimeBadge()` in `helpers/pricing.php`. During business hours it reads "We typically respond within 2–4 hours." Outside business hours it reads "We respond within 24 hours."

**Impact:** Reduces abandonment from users unsure whether the form commits them to anything.

### Seasonal Banner

Generated by `getSeasonalMessage()` in `helpers/pricing.php`. Displays contextually for:
- March: "Get ahead of spring" tip
- April/May: "Spring is our busiest season" urgency
- June: "Limited summer availability" urgency
- October: "Fall cleanup season" tip
- November/December: "Snow removal season approaching" tip

Banner is suppressed in off-peak months (July–September, January–February) to avoid crying wolf.

**Impact:** April–May urgency messaging is the highest-value moment — these are peak booking months for Vancouver landscaping.

### Service Cards (Visual Selector)

Services are now displayed as tappable cards with emoji icons rather than plain checkboxes. Cards visually highlight on selection with a green border and a checkmark.

**Impact:** Visual cards increase engagement and are mobile-optimised (larger tap targets).

### Lawn Size Selector

Shown conditionally when a lawn-related service (lawn_care, maintenance) is selected. Three options: Small / Medium / Large with square footage guidance.

**Why this matters:**
- Enables pricing estimation on the confirm page
- Feeds lead classification for value tier calculation
- Data stored in session → written to `project_description` with classification notes

### Irrigation Toggle

Shown alongside lawn size selector. Simple checkbox: "This property has an irrigation / sprinkler system."

**Why this matters:**
- Irrigated lawns grow faster → higher visit frequency → higher annual value
- Flags leads for irrigation-aware scheduling
- Triggers `priority` classification when combined with other signals

## Step 2 — Confirm Page Enhancements

### Price Estimate Display

Calculated by `calculateEstimate()` in `helpers/pricing.php` based on:
- Selected services
- Lawn size
- Irrigation flag
- Selected upsells

Displayed as a range: **$65–$95 per visit**

**Important:** These are display-only estimates for conversion optimisation. The actual quote is produced by the CRM team. The note always clarifies this.

To update pricing: edit `getPricingConfig()` in `helpers/pricing.php`. No view files need changing.

### Upsell Cards

Generated by `getRelevantUpsells()` based on selected services:

| Trigger | Upsell Shown |
|---------|-------------|
| lawn_care or maintenance selected | "Weekly Lawn Cut" (Most Popular badge) |
| lawn_care or maintenance selected | "Fertilizer Program" (+$45/visit) |
| hedge_trimming NOT already selected | "Hedge Trimming Add-on" (Bundle & Save badge) |

Upsells are checkboxes rendered as visual cards. Selected upsells are:
1. Appended to the confirm form via JavaScript before submission
2. Stored in `$data['upsells']` array in session
3. Written to `project_description` as classification metadata
4. Included in the internal notification email to the owner

**Most Popular badge** — shown on "Weekly Lawn Cut" because it is the most commonly added service in Vancouver residential landscaping (genuine signal, not fabricated).

### Availability Urgency Banner

Shown in spring months (March–June) or when urgency=asap:
- Spring: "Limited seasonal availability — we're booking fast for spring."
- ASAP: "We prioritise ASAP requests — you'll hear from us today."

## Step 3 — Success Page Enhancements

### Personalised Greeting

"Thank you, [First Name]!" instead of generic "Thank You!"

The first name is passed via session key `submitted_name` set by confirm.php.

### Enhanced Next Steps

Three-step next-steps section with icons describing the full journey from review → quote → booking. Replaces the generic "we'll review your info" text.

### SMS Opt-in Nudge

Shown only to users who did NOT check the SMS consent box. Explains the benefit of SMS updates (scheduling confirmations, crew arrival notices) and suggests they reply to the team's message to opt in.

**Why not a checkbox here:** CASL requires explicit consent at time of collection. The nudge encourages them to opt in via direct communication, which is compliant.

### Referral Incentive

$25 service credit for referring a neighbour. Just mention your name. No referral code system needed at this stage — handled manually by the owner.

**Impact:** Word-of-mouth is the highest-converting acquisition channel for residential landscaping. This plants the seed immediately after a positive quote experience.

## Pricing File Reference

**Location:** `/public/jobFlow/helpers/pricing.php`

**Functions:**

| Function | Returns | Purpose |
|----------|---------|---------|
| `getPricingConfig()` | array | Master pricing table |
| `calculateEstimate(services, size, irrigation, upsells)` | `[min, max, note]` | Per-visit estimate |
| `getRelevantUpsells(services)` | array of upsell defs | Contextual upsell selection |
| `getSeasonalMessage()` | array or null | Seasonal banner content |
| `getResponseTimeBadge()` | string | Dynamic trust badge text |

**To change prices:** Edit `getPricingConfig()`. All view logic reads from this function. No hardcoded prices anywhere in view files.
