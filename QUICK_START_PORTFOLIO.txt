💾 DATABASE SCHEMA

CREATE TABLE portfolio_projects (
  id                     int                    PRIMARY KEY AUTO_INCREMENT
  project_number         varchar(20)            UNIQUE (auto-generated: PORT-YYYY-NNNN)
  project_name           varchar(255)           Required
  description            text                   Optional full description
  location               varchar(255)           Optional location/address
  status                 enum('draft','pub')    Publication status
  featured               boolean                Prioritize on public site
  display_order          int                    Sort order (lower = first)
  categories             json                   Array of category strings
  before_image_path      varchar(512)           Before image URL/path
  after_image_path       varchar(512)           After image URL/path
  gallery_images         json                   Array of gallery image paths
  created_by             int                    User ID of creator
  created_at             timestamp              Auto-set to NOW()
  updated_at             timestamp              Auto-updated
)

❓ TROUBLESHOOTING

Q: Portfolio page shows "No projects available"
A: 1) Verify migration ran (check phpMyAdmin)
   2) Create a project and set Status to "Published"
   3) Check browser console for errors

Q: Portfolio nav item not in sidebar
A: 1) Clear browser cache (Ctrl+F5)
   2) Verify appstack_sidebar.php was updated
   3) Check for PHP syntax errors

Q: Form won't submit
A: 1) Check error message on form
   2) Verify project name is filled in
   3) Check browser console for errors

Q: Projects don't appear on public site
A: 1) Ensure Status is set to "Published"
   2) Check that database table exists
   3) Test database query in phpMyAdmin
