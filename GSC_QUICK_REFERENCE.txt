# ⚡ GSC Fix — Quick Reference

## The Problem (1 sentence)
Code adds `sc-domain:` prefix to all properties, but your property is stored as `https://mowology.ca` (URL-prefix type) so queries fail with 404.

## The Fix (1 sentence)
Store property identifiers **exactly as Google returns them**, don't transform them.

---

## Files Changed

| File | Change |
|---|---|
| **Database Schema** | Add `api_site_url`, `property_type`, `display_domain` columns |
| **sync-cron.php** | Use `api_site_url` verbatim, add validation, remove sc-domain: transformation |

## Code Changes

### Before (BROKEN)
```php
// Line 223 in old sync-cron.php
$apiSiteUrl = 'sc-domain:' . preg_replace(...); // WRONG: Hardcodes sc-domain:
```

### After (FIXED)
```php
// Line 164 in fixed sync-cron.php
$apiSiteUrl = $property['api_site_url']; // CORRECT: Uses verbatim from database
// With validation: validateSiteUrlFormat($apiSiteUrl, $propertyType)
```

## Property Types

| Type | Format | Covers | API Endpoint |
|---|---|---|---|
| **URL-prefix** | https://example.com | Exact domain + protocol | /sites/https%3A%2F%2Fexample.com/... |
| **Domain** | sc-domain:example.com | All protocols/subdomains | /sites/sc-domain%3Aexample.com/... |

**Current property:** URL-prefix (https://mowology.ca)

---

## Why It Works

```
OLD (broken):
  DB: https://mowology.ca
  -> Transform to: sc-domain:mowology.ca
  -> Query: GET /sites/sc-domain%3Amowology.ca/...
  -> Google: 404 FAILED

NEW (fixed):
  DB: https://mowology.ca
  -> Use verbatim: https://mowology.ca
  -> Query: GET /sites/https%3A%2F%2Fmowology.ca/...
  -> Google: 200 OK
```

## Error Messages

| Error | Cause | Fix |
|---|---|---|
| "Failed to fetch GSC data" | Site URL doesn't match Google's records | Migration + deployment |
| "No refresh token" | Token needs refresh | Reconnect via /crm/gsc/connect.php |
| "Invalid url_prefix format" | Corrupted identifier | Manually update DB or reconnect |
