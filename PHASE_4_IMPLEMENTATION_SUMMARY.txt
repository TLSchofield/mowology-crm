WHAT WAS BUILT

Phase 4 enables automated landing page generation from reusable templates.

Staff can now:
- Select a template (Service Landing, Portfolio Gallery, etc.)

entire page, making it possible to create 50+ geo-targeted pages in hours
instead of days.

HOW IT WORKS
================================================================================

USER WORKFLOW (for staff):

1. Click "Generate Page" in CMS
2. STEP 1: Choose template (Service Landing, Portfolio, etc.)
3. STEP 2: Select service (Lawn Care, Snow Removal, Landscaping, etc.)
4. STEP 3: Select neighbourhood (Burnaby, Richmond, Vancouver, etc.)
5. STEP 4: Review preview and click "Generate"
6. Page editor opens automatically
7. Staff edits and publishes the page

TECHNICAL WORKFLOW:

page-generator-wizard.php (UI)
   ↓ (Form submission)
   ↓
generate-page.php (API)
   ↓ (POST with generator_key, service, neighbourhood)
   ↓
page-generator.php (Engine)
   ├─ Validate variables
   ├─ Generate title: "{service} in {neighbourhood}" → "Lawn Care in Burnaby"
   ├─ Generate slug: "{service}-{neighbourhood}" → "lawn-care-burnaby"
   ├─ Create cms_pages record (status=draft)
   └─ Create cms_blocks records with substituted content
   ↓
Database (cms_pages + cms_blocks + cms_page_generations_log)
   ↓
Staff reviews in page editor
   ↓
Staff publishes page
   ↓
Page goes live with all content, metadata, and CTAs

================================================================================
TEMPLATE SYSTEM
================================================================================

Templates are JSON configurations defining:
- Page type
- Title template: "{service} in {neighbourhood} | Mowology"
- Slug template: "{service}-{neighbourhood}"
- Meta description template
- Block definitions with variable placeholders

PRE-SEEDED TEMPLATES (3 available):

1. Service Landing Page
   - Key: service-landing-basic
   - Status: ENABLED
   - Blocks: Hero + Features + Rich Text + CTA
   - Variables: {service}, {neighbourhood}
   - Use case: Generic service pages

2. Service Landing with Portfolio
   - Key: service-landing-portfolio
   - Status: ENABLED
   - Blocks: Hero + Gallery (auto-populated) + CTA
   - Variables: {service}, {neighbourhood}
   - Use case: Gallery/portfolio showcase pages
   - Note: Auto-populates with Phase 5 featured photos

3. Neighbourhood Coverage
   - Key: neighbourhood-coverage
   - Status: DISABLED (can be enabled)
   - Blocks: Hero + Rich Text + CTA
   - Variables: {neighbourhood}
   - Use case: Generic neighbourhood pages for SEO

  "neighbourhood": "burnaby",
  "custom_title": "",
  "csrf_token": "..."
}

RESPONSE (success):
{
  "success": true,
  "page_id": 42,
  "page_slug": "lawn-care-burnaby",
  "edit_url": "/crm/cms/cms-page-editor.php?id=42",
  "message": "Page generated successfully: Lawn Care in Burnaby | Mowology"
}

RESPONSE (error):
{
  "success": false,
  "error": "Missing required variables: service"
}
