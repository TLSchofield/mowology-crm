## How gates work (read this first)
- Remote source: `app-version.json` -> `android` block, read by `~/day/AppVersionFeed.kt` (60 s memory cache). Every switch caches its last value in `TrackingStore.prefs` as `<key>_last_seen` + `<key>_fetched_at`; a remembered ON expires after 24 h (`FeatureSwitchLogic.resolve`, TTL 24 h). Never fetched / false / expired = OFF. Refresh runs in `NativeDayLauncher.refreshSwitches` (`~/day/NativeDayLauncher.kt:133-176`, off main thread) and is read synchronously with `isOn(context)`.
- Production tenant (`mowology` flavor): every switch is OFF until the feed says `true`.
- Ittai tenant: `ittaiFeedDefaults()` (`~/day/AppVersionFeed.kt:~90`) injects `true` for every key in `ITTAI_NATIVE_KEYS` (webview_shell_disabled, native_auth, native_signup, native_day, native_crew_schedule, native_schedule_header, native_schedule_plus, native_timeclock, native_timesheet_v2, native_offline_start, native_queue_safety, native_tracking_setup, native_tracking_v3, native_camera, native_visit, native_photo_gallery, native_field_tools, native_invoice, native_trip_report, native_ai_office, native_quiz, native_plants, native_receipts, native_receipt_review, native_receipt_comparison) unless the feed holds an explicit boolean. `ITTAI_OPT_IN_KEYS` stay OFF for Ittai too: native_geofence_power, native_penny_receipt_card, native_job_screen, native_receipt_intake, native_product_add, native_vendor_items. Keys in NEITHER list (default OFF everywhere unless noted): office_documents, office_carousels, onboarding_brain, onboarding_contacts, receipt_auto_shoot, receipt_doc_scanner, meniscus_classic; `receipt_steady` defaults ON when never fetched.
- Three switch shapes: (a) `FeatureSwitch(prefKey, feedKey[, ittaiDefaultOn])` instance in `~/config/FeatureSwitch.kt:42` (used by Auth, Quiz, TripReport, TrackingV3, TrackingSetup, FieldTools, ScheduleHeader, Invoice, SchedulePlus, Timesheet, TimeClock, ReceiptReview, AiOffice); (b) hand-rolled object reading the same prefs shape (the 19 below); (c) legacy parse functions (`NativeDaySwitch` `~/day/NativeDayLauncher.kt:19`, `NativeCameraSwitch` `~/camera/MwCameraPlugin.kt:22`, `NativePlantsSwitch` `~/plants/PlantWorker.kt:226`, `NativeReceiptsSwitch` `~/receipts/ReceiptUploadWorker.kt:194`, `QueueSafetySwitch` `~/queue/QueueSafetySwitch.kt:14`, `WebShellSwitch` `~/auth/NativeLaunch.kt:24`, `MeniscusBarSwitch` `~/ui/ittai/ItMeniscusBar.kt:830`, Diagnostics/VitalsUpload in `~/launch/`).
- Gate column below: `FS:key` = FeatureSwitch instance; `Sw:Name` = a hand-rolled switch; `Ittai default` = key in ITTAI_NATIVE_KEYS; `opt-in` = ITTAI_OPT_IN_KEYS; `none` = no switch (always available once native day is on).
