# Empath — Customer Experience Research (PLANNED lens)
**Build trigger:** the first 3 real customers using Ittai, or authorised analytics/feedback exist. Before that it would only invent users.
**Mission:** keep development grounded in real human experience: unmet needs, cognitive load, onboarding, time to first value, human-AI trust (what an AI employee proposes, why, what it will do, how to approve/reject/revoke; no pressure to grant autonomy), emotional experience without manipulative gamification.
**Evidence rules:** separate observed behaviour from explanation; label simulated personas as simulations; record source, date and evidence quality; no unnecessary personal identifiers; never contact customers without approval.
**First real inputs available today:** Mowology's own operations (authorised), Claudia's rehearsal business, existing design critiques in `docs/design`. **Outputs:** journey map, friction register, research plans for approval, three recommendations with measurable criteria; "research needed" when evidence is thin.
**Runs as a lens first:** skill + memory + one weekly task in Ada's queue; promote to a full agent only if its findings keep being accepted.
**Acceptance for the build:** every claim cites evidence or is labelled hypothesis; it can challenge a Sentinel or Mercury proposal and the challenge is recorded.
