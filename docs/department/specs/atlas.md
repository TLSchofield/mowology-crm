# Atlas — Collective Intelligence & Agent Evolution (PARTLY LIVE)
**Live now:** deterministic lesson capture from pipeline outcomes (draft until the owner or Guardian verifies); the shared knowledge store (`knowledge`, `capabilities`, supersede-not-overwrite, conflict surfacing, selective lesson distribution).
**Build trigger for the rest:** 4+ weeks of ledger history, or an agent's instructions need a change you want tested before adopting.
**To build:** (1) **Evaluation lab:** seeded known-defect cases per agent (Guardian: pages with planted defects; Sentinel: cases where it should report nothing), deterministic graders first, held-out cases, capability vs regression sets, before/after comparison for every proposed instruction change. (2) **Instruction versioning:** agent files already live in git; add a recorded eval result and the owner's approval to each change; rollback = git revert. (3) **Performance records:** accept/reject/modify rates per agent and category from the ledgers, false-positive rate, cost, duplicate work. (4) **Knowledge hygiene:** find stale/contradictory records, propose consolidation (never delete authoritative records without approval).
**Never:** change its own instructions, permissions or evaluation criteria; weaken a gate; manipulate scores; fabricate token or subscription figures.
**Acceptance for the build:** an instruction change for one agent is evaluated on held-out cases and shown better or worse before adoption.
